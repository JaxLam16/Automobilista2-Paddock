# Corner skills and references

Open a finished recording's **Driving style → Corner skills** to inspect the local
driver's corner measurements, individual clean laps and averages. One complete
clean lap is sufficient. Rival pedal/steering inputs are not available from AMS2.

The 13 skills cover turn-in, braking point, throttle onset, brake-release shape,
peak brake input, minimum speed, front response, exit corrections, apex/exit
clearance, steering input rate, gearing exposure and throttle withdrawals.
Some are conservative motion indicators rather than measured tyre slip or proven
causes of time loss. Apex/exit clearance requires a matching measured track-edge
map. Missing evidence stays unavailable; unsupported targets do not earn green.

In **Race engineer → Corner skill overlay**, enable and save the overlay. Defaults
are trail braking, all corners, practice only, after the corner exit, six-second
hold and a small centre-screen strip. Choose skills, corners, timing, placement,
opacity and size. Optional wheel bindings cycle skills and hide/show the strip.
Use AMS2 borderless/windowed mode; the overlay does not inject game inputs.

The bar is green in the middle, yellow then red at the extremes, with one short
feedback phrase. Without a suitable reference, only supported technique feedback
is graded. A missing pace target says **Target needed**. A personal reference
measures differences from that example, not professional or optimal driving.

References require the same track layout/length. Exact car is preferred; matching
class is allowed with wider bands and condition/setup caveats. Targets select fast
clean corner passes across laps, retaining linked-corner payoff and each source
lap. They do not assemble an impossible averaged pedal trace.

Expand **Private reference packs** on Driving style to export a `.paddockref` file
or import one received from a friend. Import is also in live overlay settings.
The file contains calculated corner statistics and selected input snippets at 5 m
spacing, not the complete recording or any voice files. Imported references can
be selected for live and recorded comparisons; selected reference brake, throttle
and signed-steering traces retain their source lap. Imported figures are not
independently verified against the original telemetry. Identical imports keep one
copy. There is no automatic league upload or synchronization.
